# Campfire Mod

Multiplayer funnies for funny multiplayer :3

---

# Features
- Campfire (soon™)
- Log lift to the sun (initiation ritual)
- Catch & release other players (with consent)
- Catch & ***kill*** other players (with the inhabitant skin)
- Respawn oldest dead player keybind
- Ragdoll keybind
- Toggle inhabitants keybind

## Actions
All actions in the mod are triggered by G + another key. Why G? Cuz that's what Ultimate Skin Changer uses to make it consistent.
| Action | Keybind |
| ------ | ------- |
| Grab player (normal) | Walk up and press E. Press G + Q to release. (only works if the other player has it toggled on) |
| Grab player (inhabitant) | G + 3 when close to and facing a player. |
| Respawn oldest dead player | G + R |
| Ragdoll | G + U |

### Settings
| Setting | Description |
| ------- | ----------- |
| Allow others to grab | Toggles whether or not others can grab you normally. (Does not change inhabitant grab) |
